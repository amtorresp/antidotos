# Antídotos

Este repositorio contiene un pequeño juego de consola para unir cada fármaco con su antídoto.

## Requisitos

- Python 3

## Cómo jugar

Ejecuta el archivo `match_antidote_game.py`:

```bash
python3 match_antidote_game.py
```

Sigue las instrucciones en pantalla y escribe el número del antídoto que creas correcto para cada fármaco.
